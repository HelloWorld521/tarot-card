# 00 · 项目说明

## 这是什么

一个网页小游戏：为「恋人」建立一张角色卡。玩家从 16 个性格品质里选 3 个，翻面后看到每个品质自带的代价，得到一张有名字、有头像、有三行代价、有四维得分与总分的角色卡；这张卡会存进游戏内的通讯录，还可以导出成一张竖版分享图发给别人。

核心体验是一句话：**你选的是优点，拿到的是代价。** 选卡时只看得到品质的正面场景，翻面之后才知道它另一面是什么。

## 给谁玩

- 收到链接的朋友：手机打开，不登录、不装 App、不需要看懂规则，30 秒内能走完一轮。
- 作者本人与学习者：把它当作「状态机 + 规则判定 + 存档」的完整样本阅读（`game-learn` 项目就是这么用它的）。

## 成功标准

以「一个不懂规则的人，用手机打开链接」为准：

1. 不用口头指导，能自己完成：开始 → 选关系 → 填名字 → 选 3 个品质 → 翻面 → 看结果 → 存卡。
2. 选满 3 张之前，「继续」不可点；第 4 张点不上，且能明白为什么。
3. 翻面后能清楚看到「三个品质」和「三个代价」的对应关系，组合文案命中时文案与所选品质一致；结果页给出总分与四维分项。
4. 刷新页面后，通讯录里的卡还在；可以点开详情、可以删除；没有得分字段的老卡仍能正常显示。
5. 分享图是 1080×1440 竖版，图上只有正面信息（名字、三个品质、钩子、总分），二维码能扫出线上地址；四维分项与代价不出现在图上。
6. 390 宽手机上无横向滚动、无双击缩放抖动；桌面端排版不崩。
7. 整个项目零依赖、无构建，直接静态托管在 `/tarot-card/` 子路径下可运行。

第 4 到 7 条是可以通过命令复现验证的，不靠主观判断。

## 不做什么

- **不做账号与后端**：没有登录、没有云同步，通讯录只存在浏览器 `localStorage`（键 `tarot-lover-cards-v1`）。
- **不开放其他关系**：本版只有「恋人」可选，朋友 / 同事在关系页显示为未解锁灰态，不实现其卡池。
- **不做实时对战、付费、埋点统计**：这一版只验证「选品质 → 揭示代价 → 收藏 → 分享」这条闭环。
- **不追求动画与特效堆叠**：视觉是近黑偏紫、细金线、衬线大字、克制的塔罗感；不用发光堆叠、不用 emoji、不引动画库。
- **不做多语言**：界面文案全部中文，集中在 `data/config.js`。
